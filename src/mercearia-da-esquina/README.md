# Mercearia da Esquina

Template responsivo de página única para uma mercearia de bairro. Abra `index.html` no browser; não é necessário instalar dependências.

Edite o HTML para adaptar o nome, produtos, morada, horário, contactos e ligação do mapa. Os dados de contacto e a localização são exemplos e devem ser substituídos antes da publicação. As cores e a apresentação estão em `assets/style.css`; o menu móvel está em `assets/main.js`. As fotografias e fontes são carregadas remotamente e podem ser substituídas por ficheiros locais.
