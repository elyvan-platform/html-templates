# Trilho — Learning Platform

Template independente de plataforma de cursos online, em português de Portugal. Abra `index.html` no browser ou use a montra do projeto.

Inclui catálogo com pesquisa, categorias e nível; detalhe de curso com currículo; área de aula com módulos; marcação de lições concluídas; quizzes demonstrativos; página de progresso. O progresso fica em `localStorage` (chave `trilho-progresso-v1`), sem backend nem autenticação. Os cursos estão definidos no início de `assets/main.js`. Nomes, formadores e conteúdos são fictícios; não há ficheiros de vídeo nem imagens remotas.
