# Architecture Studio

Template independente de arquitetura e interiores em PT-PT. Abra `index.html` diretamente ou execute `npm run dev` na raiz e visite `/templates/architecture-studio`.

HTML, CSS e JavaScript nativos, sem dependências, fontes remotas, backend ou armazenamento. Galeria filtrável por tipologia, três páginas de projeto, atelier, equipa e formulário com validação nativa e confirmação explícita de demonstração. As visualizações SVG locais são estudos conceptuais originais; projetos, áreas e equipa são fictícios. Não representam fotografias de obras executadas.

Edite os textos nas páginas HTML, as cores em `style.css` e os estudos em `assets/`. `preview.svg` é a entrada visual no catálogo. O formulário não envia nem guarda dados; a validação respeita os campos obrigatórios, formato de email, consentimento de demonstração e comprimento mínimo da descrição. Todas as tipologias têm projetos; existe também uma mensagem de estado vazio para extensões futuras.

A navegação mantém-se visível no telemóvel. Foco visível, ligação para saltar o cabeçalho, estados anunciados e movimento reduzido estão incluídos.
