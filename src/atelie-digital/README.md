# Ateliê Digital

Marketplace demonstrativo de recursos digitais em PT-PT. Abra `index.html` diretamente ou explore-o no catálogo do projeto. Pesquisa, categorias, filtros, ordenação, favoritos e carrinho funcionam localmente; favoritos e carrinho são guardados no armazenamento do navegador quando disponível. O checkout é apenas ilustrativo e não processa pagamentos.
