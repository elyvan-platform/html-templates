# Velocitá Garage — Automotive Showcase

Template de página única em português de Portugal para showcase de motos e automóveis: hero, modelo em destaque com troca de cor, catálogo com filtro/pesquisa/ordenação, comparação de fichas técnicas, galeria fullscreen e formulário de contacto demonstrativo.

Abra `index.html` no browser ou use a montra do projeto. Sem dependências nem build.

## Estrutura

- `index.html` — marcação semântica
- `assets/data.js` — modelos, cores e especificações (**todos fictícios**)
- `assets/main.js` — interações; as ilustrações são SVG geradas localmente
- `assets/style.css` — tema escuro (variáveis em `:root`)

## Notas

- Preços e fichas técnicas são exemplos; o formulário não envia nem guarda dados.
- Galeria: setas do teclado navegam, `Esc` fecha. `prefers-reduced-motion` desativa animações.
