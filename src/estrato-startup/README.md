# Estrato — Startup Pitch

Template independente em PT-PT para uma startup fictícia de operações circulares. HTML, CSS e JavaScript nativos, sem dependências, fontes remotas ou pedidos externos.

Abra `index.html` diretamente ou execute `npm run dev` na raiz e explore o catálogo. A entrada é descoberta automaticamente; `npm run build` atualiza o catálogo estático.

## Demonstração

- Navegação por âncoras, menu móvel com estado expandido e fecho por Escape.
- Seletor de materiais: Madeira e Têxtil mostram ligações fictícias; Embalagens apresenta um estado vazio.
- Formulário com validação nativa, rejeição de texto só com espaços e confirmação local. Não envia nem guarda dados; use dados fictícios. Sem JavaScript, o envio fica desativado.
- Gráfico e métricas de tração, equipa, mercado e roadmap explicitamente demonstrativos. Não existem dados financeiros reais.

A identidade visual usa tipografia de sistema e ilustrações geométricas em CSS. Layout adaptável e suporte a `prefers-reduced-motion`. Sem JavaScript, o conteúdo e a navegação mantêm-se disponíveis e o produto mostra o cenário inicial.
