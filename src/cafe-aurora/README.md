# Café Aurora

Template de página única para um café de bairro, em português de Portugal. Abra `index.html` diretamente no browser ou use a montra do projeto. Inclui apresentação, ementa, morada e horários, com navegação adaptada a dispositivos móveis.

O nome, os preços, a morada, os horários e o contacto são exemplos fictícios e devem ser substituídos antes da publicação. Edite o conteúdo em `index.html`, as cores e estilos em `assets/style.css` e o menu móvel em `assets/main.js`. As fotografias são carregadas remotamente do Unsplash; substitua os URLs para usar imagens próprias. Não há formulário, reservas ou encomendas integrados.
