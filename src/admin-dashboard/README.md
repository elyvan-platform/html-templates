# Painel Meridiano (Admin Dashboard)

Template independente de painel de gestão de utilizadores e operações internas, em português de Portugal. Abra `index.html` no navegador; não requer instalação nem dependências.

Inclui KPIs, gráficos SVG (linha e barras, com tabela de dados alternativa), tabela com pesquisa, filtros, ordenação e paginação, criação/edição em modal, ações por linha (editar, suspender/reativar, remover com confirmação), registo de operações e estados de carregamento, vazio e erro (botão "Simular erro").

Os dados são fictícios e ficam apenas em `localStorage`; "Repor dados" restaura o exemplo. Não há backend, autenticação nem pedidos externos. Cores e tokens estão em `assets/style.css`; dados de exemplo em `assets/main.js`.
