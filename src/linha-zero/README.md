# Linha Zero

Template independente de uma montra automóvel e moto. Abra `index.html` num navegador ou aceda à entrada na montra do repositório. As imagens são locais e os modelos, especificações e contacto são fictícios. A seleção de ambiente aplica um tratamento visual à fotografia; não representa uma cor de pintura real. A galeria suporta teclado e o botão de contacto apresenta apenas uma confirmação local, sem enviar dados.
