# Clínica Movimento

Template de página única para uma clínica de fisioterapia, em português de Portugal. Abra `index.html` no navegador; não é necessário instalar dependências. O menu adapta-se a ecrãs pequenos e as secções apresentam a clínica, serviços, equipa e contactos.

O nome, morada, horários, contactos e imagens são exemplos e devem ser substituídos antes da publicação. As imagens são carregadas do Unsplash e as fontes do Google Fonts; substitua-as por ficheiros locais se necessário. As cores e tipografia estão definidas em `assets/style.css`.

O formulário é apenas demonstrativo: não envia nem guarda dados e não efetua marcações. Para receber pedidos, integre um serviço de envio adequado em `assets/main.js` e atualize a mensagem junto ao formulário.
