# Portfolio Developer

Template de página única para um portefólio de developer sénior, em português de Portugal. Abra `index.html` no browser ou use a montra do projeto.

Inclui hero com CTA, projetos filtráveis com detalhe, competências, percurso, links sociais, formulário validado localmente e botão de copiar email, com tema claro/escuro. Todos os dados são fictícios; edite o conteúdo em `index.html` e as cores em `assets/style.css`. Não há backend nem envio real do formulário; sem imagens ou dependências externas.
