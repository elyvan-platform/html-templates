# Miguel Costa — Portfolio Developer

Template independente em HTML, CSS e JavaScript, sem dependências nem pedidos a APIs. Abra `index.html` diretamente ou utilize `npm run dev` na raiz para explorar a entrada do catálogo e o preview responsivo.

Inclui filtros de projetos, quatro estudos de caso em diálogo nativo (Escape e devolução de foco), tema claro/escuro persistido quando permitido, cópia de email com alternativa manual e formulário com validação local acessível. O formulário não envia nem guarda dados.

Identidade, empresas, projetos e resultados são fictícios. O endereço usa o domínio reservado `.example`; os links sociais abrem as páginas públicas dos serviços e estão identificados como exemplos. Substitua estes dados antes de publicar. As composições visuais dos projetos são HTML/CSS locais, sem imagens ou fontes remotas.

Conteúdo: `index.html`. Estilos e pontos de quebra: `assets/style.css`. Dados dos estudos de caso e interações: `assets/main.js`. O catálogo é gerado na raiz com `npm run build`.
