# Farmácia do Jardim

Template institucional de página única para farmácias, em português de Portugal. Abra `index.html` diretamente no navegador ou execute `npm run dev` na raiz e selecione o template na montra.

Inclui apresentação, serviços farmacêuticos, áreas de cuidado, horário, contactos e perguntas frequentes. O menu móvel funciona por teclado, fecha com Escape e mantém a navegação disponível sem JavaScript. O layout adapta-se a telemóveis e respeita a preferência por movimento reduzido. A ilustração é feita em CSS, sem imagens, fontes ou dependências externas.

## Personalização

- Altere os textos, nome, serviços, horário, morada, telefone e email em `index.html`.
- Ajuste a paleta nas variáveis de `assets/style.css` e o menu em `assets/main.js`.
- Substitua a ligação genérica ao mapa de Lisboa pela localização real.
- Confirme os serviços efetivamente disponíveis, respetivos preços e condições antes de publicar. Acrescente os dados legais e profissionais aplicáveis à farmácia.

Todos os dados são fictícios, incluindo o email com domínio reservado `.example`. Os botões de contacto abrem o telefone ou o cliente de email; não existe envio de formulários, marcação, venda de medicamentos ou tratamento de dados de saúde. A ilustração decorativa não representa um produto à venda. O diretório de farmácias de serviço é um serviço externo.
