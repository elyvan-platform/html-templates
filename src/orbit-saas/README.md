# Orbit — SaaS Landing Page

Template independente em português para um software fictício de gestão de projetos. Abra `index.html` no navegador ou use `npm run dev` na raiz e visite `/src/orbit-saas/index.html`.

Inclui navegação móvel, prévia ilustrativa do produto, funcionalidades, preços com alternância mensal/anual, FAQ e diálogo de seleção do plano. A seleção é demonstrativa: não cria contas nem recolhe dados. Valores, marcas e testemunhos são fictícios.

HTML, CSS e JavaScript sem dependências de execução. As fontes Google são opcionais, com alternativas locais. A página respeita a preferência de movimento reduzido. Personalize textos, tokens CSS e preços no HTML antes de integrar um serviço real.
