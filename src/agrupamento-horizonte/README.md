# Agrupamento Horizonte

Template estático e responsivo para um agrupamento de escolas. Abra `index.html` num navegador ou aceda ao template através da montra do repositório.

O nome, as escolas, os textos, os contactos e os horários são exemplos e devem ser substituídos antes da publicação. As fotografias são carregadas a partir do Unsplash e as fontes a partir do Google Fonts; existem fontes de reserva para utilização sem acesso à rede. As ligações de acesso rápido apontam para secções da própria página e podem ser adaptadas aos serviços reais do agrupamento.
