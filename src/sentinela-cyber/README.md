# Sentinela Cyber

Template de página única para uma empresa de cibersegurança, em português de Portugal. Estética preto/charcoal com verde contido e detalhes de terminal. Abra `index.html` no browser ou use a montra do projeto.

Inclui serviços, capacidades SOC (separadores acessíveis), indicadores ilustrativos, processo, casos de uso, FAQ em accordion e formulário de contacto validado localmente. A consola do hero é puramente decorativa. Nome, números, telefone e casos são fictícios; o formulário não envia dados nem usa backend. Sem dependências nem recursos externos.
