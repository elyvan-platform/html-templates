# Pastelaria Doce

Template de página única para uma pastelaria, em português de Portugal. Abra `index.html` no navegador ou use a montra do projeto. Inclui especialidades, história, contacto para encomendas, morada e horários, com navegação adaptada a dispositivos móveis.

O nome, a morada, o horário e os contactos são exemplos fictícios e devem ser substituídos antes da publicação. Edite o conteúdo em `index.html`, os estilos em `assets/style.css` e o menu móvel em `assets/main.js`. As fotografias são carregadas remotamente do Unsplash e podem ser substituídas por imagens próprias. O botão de encomenda abre o programa de email; não existe processamento de encomendas integrado.
